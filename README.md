# AI-resume-assestant
# 📄 ATS Resume Scorer (Streamlit + Gemini Flash)

This app lets users upload a resume (PDF/DOCX/TXT), then uses **Gemini Flash** to:
- compute an **ATS score (0–100)**
- provide **score breakdown**
- suggest **specific improvements**
- optionally provide **rewrite suggestions**

---

## ✨ Features
- Upload resume (PDF/DOCX/TXT)
- ATS scoring & structured improvement feedback
- Returns results in JSON (rendered in Streamlit)
- Handles basic extraction failures gracefully
