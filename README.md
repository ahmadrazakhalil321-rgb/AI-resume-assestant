# ATS Resume Evaluator & Analyzer

An interactive Web Application built with **Streamlit** and **Google Gemini Flash** to parse resumes (PDF, DOCX, TXT), score them against Applicant Tracking Systems (ATS) standards, and provide actionable bullet-point improvements.

## Features
- **Multi-format Support**: Upload PDF, DOCX, or plain text resumes.
- **ATS Scoring**: Get an estimated ATS match score out of 100.
- **Job Match Analysis**: Optional job description input to compare your resume directly against specific role requirements.
- **Improvement Suggestions**: Receive specific rewrites, formatting tips, and key skills to add.
